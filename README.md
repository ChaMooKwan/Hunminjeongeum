# 🎮 훈민정음

> **실시간 소켓 통신 기반 초성 맞추기 게임**  
> 제한된 시간 안에 주어진 초성을 보고 정답을 맞추는 멀티플레이 게임입니다.

<br>

## 📌 프로젝트 소개

**훈민정음**은 여러 사용자가 실시간으로 참여하여 초성을 맞추는 온라인 게임입니다.

실시간 소켓 통신을 활용하여 플레이어 간 게임 상태를 동기화하고,  
주제별 단어 데이터를 기반으로 다양한 초성 퀴즈를 제공합니다.

또한 LLM API를 활용하여 게임 콘텐츠 확장 및 사용자 경험 향상을 목표로 개발했습니다.

<br>

## ✨ 주요 기능
(생략)
```text
kr.ac.sunmoon.hunminjeongeum 프로젝트 디렉토리
├── 🏗️ app (앱 초기화 및 조립 - 차무관)
│   ├── di/                 # 미정(의존성 주입(Koin 등) 모듈 세팅)
│   └── App.kt              # 앱의 최상위 진입점 및 네비게이션(화면 이동) 관리
│
├── ⚙️ core (공통 유틸리티 및 설정)
│   ├── network/            # [정윤성] Socket 설정
│   ├── database/           # [이태석] Supabase 클라이언트 초기화 설정
│   └── theme/              # [이동욱] Color, Typography 등 디자인 시스템
│
├── 🎨 presentation (UI 및 화면 - 이동욱 & 정윤성)
│   ├── components/         # [이동욱] 재사용 가능한 UI (타이머, 점수판, 버튼 등)
│   ├── screens/            # 각 화면별 UI 구성(일단 메인 화면만 존재)
│   │   ├── mainScreen      # [이동욱] 퀴즈 메인 화면 
│   └── viewmodels/         # [정윤성] 화면의 상태 관리 및 비즈니스 로직 연결 (8월 4일은 채팅방만)
│
├── 🧠 domain (비즈니스 로직 및 규칙 - 정윤성 & 강서윤) [8월 4일은 제외]
│   ├── model/              # 데이터 모델 (QuizWord, ChatMessage, Score, Hint 등)
│   ├── repository/         # Repository 인터페이스 (Data 계층과 연결되는 뼈대)
│   └── usecase/            # 핵심 비즈니스 로직 (단일 행동 단위)
│       ├── game/           # [정윤성] 점수 계산, 콤보 계산, 정답 검증 로직
│       ├── chat/           # [정윤성] 채팅 메시지 검증 및 필터링 로직
│       └── ai/             # [강서윤] 프롬프트 튜닝, 난이도별 힌트 포맷 생성 로직
│
└── 💾 data (데이터 처리 및 외부 통신 - 강서윤, 이태석, 정윤성)
├── repository/         # domain/repository 인터페이스의 실제 구현체들
├── remote/             # 외부 서버 통신
│   ├── ai/             # [강서윤] OpenAI API 통신 클라이언트 및 DTO
│   └── socket/         # [정윤성] 실시간 웹소켓 통신 (채팅 실습 코드 적용)
└── supabase/       # [이태석] Supabase 연동
```
